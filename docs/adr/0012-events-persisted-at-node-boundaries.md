# 事件只在节点边界落库

SSE 事件分两类对待。结构性事件（Invocation 与节点的开始、完成、失败、跳过、等待输入、终态）同步落库，是审计与断线回放的依据。流式增量（llm_delta、answer_delta）不落库，只在内存中广播并按时间合并。理由：逐 token 落库意味着每路流每秒几十到上百次写入，会先于其他任何环节耗尽单机并发的目标，而回放 token 碎片没有价值。

## Consequences

- Last-Event-ID 回放的保证范围是结构性事件；断线重连的客户端从 node_completed / invocation_finished 取完整文本，流式增量只在连接存活期间可得
- 节点开始事件必须先落库再执行：它是在途检测的唯一依据（ADR-0011）
- 流式增量无法跨实例送达，这是本期只支持单实例的原因之一（ADR-0001）
